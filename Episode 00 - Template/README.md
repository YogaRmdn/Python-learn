# BAB 1 - Template Program Python

## Apa yang Dipelajari

- Struktur dasar program Python
- Menjalankan program Python pertama kali
- Fungsi `print()` untuk menampilkan output ke layar
- Cara menjalankan file `.py` di terminal

## Penjelasan Kode

Berikut adalah isi file `Main.py`:

```python
print("helo dunia!!!!!!!")
print("apa kabar kalian?")
print("instalasi berhasil")
```

### Penjelasan Baris per Baris

**Baris 1:**
```python
print("helo dunia!!!!!!!")
```
- `print()` adalah **fungsi bawaan Python** untuk menampilkan teks (atau data lainnya) ke layar/terminal.
- Teks di dalam tanda kutip `"helo dunia!!!!!!!"` disebut **string** (kumpulan karakter).
- Setelah program dijalankan, teks `helo dunia!!!!!!!` akan muncul di layar.

**Baris 2:**
```python
print("apa kabar kalian?")
```
- Sama seperti baris pertama, `print()` menampilkan teks `"apa kabar kalian?"` ke layar.

**Baris 3:**
```python
print("instalasi berhasil")
```
- Menampilkan teks `"instalasi berhasil"` ke layar. Ini menandakan bahwa instalasi Python dan environment sudah berhasil.

### Cara Menjalankan

1. Buka terminal atau command prompt.
2. Masuk ke folder yang berisi file `Main.py`.
3. Ketik perintah:
   ```bash
   python Main.py
   ```
4. Maka akan muncul output:
   ```
   helo dunia!!!!!!!
   apa kabar kalian?
   instalasi berhasil
   ```

## Analogi

Membuat program Python pertama seperti **menulis surat pertama**:
- `print()` adalah seperti **pensil** yang kamu gunakan untuk menulis.
- String di dalamnya adalah **tulisan** yang kamu tulis di kertas.
- Menjalankan program di terminal adalah seperti **mengirim surat** tersebut ke orang lain (kamu mengirim instruksi ke komputer untuk menampilkan tulisan).
